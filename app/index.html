HOW IT WORKSAI, privacy & limits +

A quantized MiniLM sentence model turns descriptions into 384-number vectors. Cosine similarity finds related meanings. A separate, limited rule layer excludes named colors or item types. Similarity is not an ownership probability; the fixed 0.40 cutoff is a prototype heuristic.

Model: Xenova/all-MiniLM-L6-v2 (Apache-2.0). Transformers.js 3.7.2 (Apache-2.0), ONNX Runtime Web 1.22.0-dev.20250409-89f8206ba4 (MIT). CPU via WebAssembly. No GPU, account or paid API required.

On first use, this host sends model and runtime files to your browser (about 45 MB). The host can see asset requests and connection metadata, but search descriptions are not sent. No third-party requests or analytics are part of the app. Search can continue in an already loaded tab without a network; offline first visits or reloads are not promised.

English only; short descriptions work best. Limited negation grammar, color aliases and uncertain matches need human review. The dataset is fictional; no recovery-rate or real-user claims.
